# quanttide-gallery-of-pi-agent

量潮 Pi 智能体案例集 — Pi 智能体实践案例与成果展示。

## 定位

gallery 是案例的公开展示层：内容可能被公开访问，脱敏是入库的前置条件。

与同域（`adapters/quanttide-pi`）资产的分工：

| 资产 | 承担 | 问题 |
|---|---|---|
| `data/context` | 驱动 | 现在带着什么上下文干活？ |
| `docs/handbook` | 规范 | 具体怎样做？ |
| **gallery（本仓库）** | 展示 | 做过哪类事、教训是什么？ |

## 概述

本仓库用于维护量潮 Pi 智能体的实践案例，包括：

- [pi-hermes-memory 案例](./pi-hermes-memory/index.md)：提示词原文三件——memory-pin（授权注入）、memory-policy（效力条款）、后台复习（抽取器）。
